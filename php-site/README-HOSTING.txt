====================================================================
দরগাহপুর সংবাদ (PHP সংস্করণ) — হোস্টিং আপলোড নির্দেশিকা
====================================================================

✅ ১ মিনিটে cPanel / শেয়ার্ড হোস্টিংয়ে আপলোড করার নিয়ম (কোনো MySQL সেটআপ ছাড়াই!)

ধাপ ১: আপনার cPanel-এ লগইন করে File Manager ওপেন করুন এবং public_html ফোল্ডারে যান।
ধাপ ২: উপরের Upload বাটনে ক্লিক করে dargahpur-sangbad-php.zip ফাইলটি আপলোড করুন।
ধাপ ৩: আপলোড শেষ হলে জিপ ফাইলটির উপর রাইট-ক্লিক করে Extract করুন।
ধাপ ৪: এবার আপনার ডোমেইন (যেমন: https://yourdomain.com) ভিজিট করুন!

ব্যস! প্রথমবার ভিজিট করলেই সাইটটি নিজে থেকেই SQLite ডাটাবেস (data/dargahpur.sqlite)
এবং সব প্রাথমিক সংবাদ, বিভাগ ও সেটিংস তৈরি করে চালু হয়ে যাবে।

--------------------------------------------------------------------
অ্যাডমিন প্যানেল লগইন তথ্য:
--------------------------------------------------------------------
লিংক:      https://yourdomain.com/admin/login.php
ইউজারনেম:  rifaz
পাসওয়ার্ড:  rifaz

⚠️ নিরাপত্তার জন্য প্রথমবার লগইনের পর "পোর্টাল সেটিংস" থেকে পাসওয়ার্ড পরিবর্তন করে নিন।

--------------------------------------------------------------------
ঐচ্ছিক: আপনি যদি SQLite-এর বদলে MySQL ব্যবহার করতে চান:
--------------------------------------------------------------------
১. cPanel → MySQL Databases থেকে একটি ডাটাবেস ও ইউজার তৈরি করুন।
২. config.php ফাইলটি এডিট করে:
      define('DB_DRIVER', 'mysql');
      define('MYSQL_DB', 'আপনার_ডাটাবেস_নাম');
      define('MYSQL_USER', 'আপনার_ইউজারনেম');
      define('MYSQL_PASS', 'আপনার_পাসওয়ার্ড');
   বসিয়ে Save করুন।
৩. সাইট ভিজিট করলেই টেবিল ও প্রাথমিক ডাটা স্বয়ংক্রিয়ভাবে তৈরি হয়ে যাবে
   (অথবা চাইলে phpMyAdmin-এ database.sql ইমপোর্ট করতে পারেন)।

সর্বনিম্ন রিকোয়ারমেন্ট: PHP 7.4 বা PHP 8.x (PDO SQLite বা PDO MySQL চালু থাকতে হবে)।
